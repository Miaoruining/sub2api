# 八格环形抽奖界面

## 改动范围

- 仅调整前端布局和开奖展示，不修改后端概率、前三次规则、充值资格、活动时段或每日预算。
- 九宫格外围八个方块，中心为抽奖按钮。顺时针依次为：1、5、下次再来、10、20、50、下次再来、100。
- 两个「下次再来」格共享服务端无奖结果，不代表无奖概率为 2/8，也不增加抽奖次数或重复请求。
- 使用一个光框沿相邻格连续平移，每步仅使用 transform 动画；收到真实结果后至少再转一圈，逐步减速后抵达目标，停留片刻再揭晓。
- 无奖按减速开始时的位置，顺时针选择接下来最近的无奖格。以格子序号区分两个相同结果，避免双格同时选中和结束瞬移。
- 保留错误处理、幂等重试、防重复点击、卸载清理及系统减少动态效果支持；沿用现有 Vue/Tailwind 界面和红色风格。
