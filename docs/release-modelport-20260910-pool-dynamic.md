发布时生产拼单商品、订单和独立号池资源均为 0。本次没有上传本地演示数据、创建付费订单或调用客户上游账号。真实 OAuth 采样、真实请求的动态预占与校准仍需在测试账号就绪后先以动态观察模式验收，不能将本次基础发布验收视为真实订阅的逐笔额度精度验证。

回退优先保留新增数据库结构，仅回退应用；不要恢复旧备份覆盖发布后的真实消费。若已有正式动态订单发货，旧应用不具备相应动态限额约束，应先暂停受影响入口并评估兼容性，再决定回退方式。
