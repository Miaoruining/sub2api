# ModelPort 自动路由与模型广场

## 用户入口

- API 密钥 → 新建或编辑 → 自动分组 → 路由策略：智能（默认）、低价优先、稳定优先。
- 设置保存在密钥上，桌面客户端无需改请求格式。固定分组密钥不受影响。
- 管理员 → 系统设置 → 功能 → 模型广场 → 展示样式：当前卡片式 / 原版 Sub2API。保存后刷新广场，全站使用所选样式；没有历史设置时保留卡片式。
- 管理员的分组排序只影响基础展示，不再控制调用顺序。

## 目录与权限

同名、同平台、同计费单位模型合并展示。筛选某一分组后打开详情，仍展示该模型的全部可见分组价目。私有分组仍受原有可见性权限约束，不因合并或样式切换泄露。

价格展示与调用资格分开：详情中的智能候选来自用户授权、活跃分组、可调度账号与明确注册的模型；仅有价目但不满足条件的线路标记“仅展示价格”。不把价卡存在等同于上游支持模型。

卡片式的分组、厂商和模型排序为 OpenAI → Claude → Gemini → Grok；分组标签依次为绿、红、蓝、紫。原版复用既有分组价目表组件。

## 策略规则

首先取得合法候选，再排序，不增加授权集合之外的分组。每次实际尝试仍重新鉴权，重新检查余额、订阅、限额并按命中分组结算。

- 三种策略都把最近 60 秒发生线路故障的分组放后面，不永久删除；其余线路都不可用时仍允许恢复探测。
- 智能：错误风险 60%、参考价格 30%、首响应字节延迟 10%，数值越低越优先。
- 低价：参考价优先，同价比较错误风险。
- 稳定：错误风险优先，再比较首字节延迟、参考价。
- 同分按分组 ID 确定顺序，不使用管理员展示排序。

参考价格通过现有模型定价解析器与用户专属倍率计算，不只比较分组倍率。Token 模型以 1k 输入 + 1k 输出作为统一参考；应用当前高峰和渠道分时因子。按次/图片有默认价时比较默认档，图片独立倍率仍独立使用。未知价不作为免费。实际请求的缓存命中、长上下文、尺寸、优先服务档、套餐等可能改变最终费用，因此参考低价不等于对任意请求都能保证最低账单。原计费链保持不变。

## 健康观测边界

只统计自动路由实际请求，不额外调用上游产生探测费用。指标按分组 + 模型隔离，保留本进程近期观测（10 分钟过期，上限 512 项），EWMA 系数为 0.2，少样本向未知先验收缩。进程重启、不同实例之间不会共享样本；这不是全站历史 SLA，也不是供应商身份或模型质量认证。

SSE 必须观察顶层协议完成信号（Responses `response.completed`、Messages `message_stop`、Chat `[DONE]`），不是 HTTP 200 即成功。已知协议未完成关闭或明确错误会降级后续排序。超大事件无法完整观察时视为未知；Gemini 原生流没有上述终止标识时也不伪造完成率。用户取消、下行写失败、普通参数/余额/用户限额错误、token 计数请求不计入正常线路表现。

成功流立即透传；仅保留最多 64 KiB 的观测残行。已向用户输出后绝不跨组重放，也不拼接两条回答。原跨组最多 8 次尝试限制保持不变。

响应头 `X-Sub2API-Group-ID` 和 `X-Sub2API-Routing-Strategy` 可用于排查实际选择。

## 发布与回退

新增迁移 `236_api_key_routing_strategy.sql` 只扩展密钥策略列，默认 smart，并限制合法枚举；不删除或重建分组。认证快照升级为 v26，覆盖策略字段。广场样式使用已有 settings 存储，不需要新表。

发布前应备份数据库、保留旧镜像并进行候选实例验收。切回原版广场只改展示，不是后端版本回滚。旧程序可以忽略新增列，但不具备本次策略逻辑。请勿为了回退外观删除用户分组、价卡或密钥。
