# ModelPort SEO / GEO 第二阶段

本阶段以真实使用问题和站点结构为重点，不通过批量低质页面、虚假评价、重复关键词或虚构厂商背书争取曝光。此文不代表已获得收录或排名。

## 实现范围

- `/learn/model-routing`：解释统一密钥的权限范围、模型可见性、自动切组和实际分组计费，以及流式请求开始后的重试边界。
- `/learn/troubleshooting`：提供 401、403、404、429 与服务端错误的检查顺序，强调结合错误正文、实际请求路径及用量记录判断，不无限重试。
- 指南目录和相关旧文新增普通 HTML 内链，保持无需 JavaScript、无需登录即可阅读公开正文；不开放个人模型报价或私有 API。
- 可见面包屑与 `BreadcrumbList` 从同一份结构生成，附加稳定 WebPage ID 与 `zh-CN` 语言标识。保留可信固定 canonical 域名及 CSP nonce。
- 自动测试覆盖每页目录可发现性、标题/路径唯一性、内部链接有效性、结构化数据及可见面包屑的一致性；站点地图随正式公开页面列表更新。

新增页面是使用说明，不宣称所有渠道或模型已启用，不新增站内收费项目，不改变抽奖、分组路由、订单或鉴权行为。

## 本地验证

- `go test -race -tags embed ./internal/web` 通过，覆盖 9 个公开指南、目录内链与结构化数据。
- `go test ./internal/web` 非嵌入版本编译通过（该模式无测试）。
- `go build -tags embed ./cmd/server` 通过，输出至隔离临时目录。
- `git diff --check` 通过。本阶段未改前端依赖、数据库迁移和部署配置。
- 线上既有站点地图只读检查为 200 / application/xml；该检查属于第一阶段基线，不代表新增两页已上线。

## 发布与 Search Console

本阶段已于 2026-09-10 北京时间 09:33:49 完成生产发布，应用提交 `68d990b23`。新页面、10 项站点地图、面包屑、canonical、404 和 API 鉴权均已在外网验证，详见 `release-modelport-20260910-seo2.md`。发布不等于 Google 已收录。

Search Console 仍需确认站点所有权。站点所有者完成验证后：

1. 检查 `https://modelport.top/sitemap.xml` 是否已提交及最近读取状态，已有时避免重复创建。
2. 对首页、指南目录、路由与排错页进行 URL 检查，记录用户声明和 Google 选择的 canonical、索引许可、抓取状态及拒绝原因。
3. 实时测试确认新 HTML 可抓取后，按需要请求编入索引；请求并不保证收录。
4. 保存首次可用的搜索表现基线：查询、页面、国家/地区、设备、展示、点击、CTR 与平均位置。新站无数据时记录“暂无数据”，不是零排名。
5. 按相同时间区间比较后续数据，分别看品牌词、API 中转相关词和接入/排错长尾词，不把物流“中转站”等不相关意图混入结果。

当前没有站点所有权报告、提交回执或排名数据，不编造提升百分比；不自动修改 DNS、购买外链或投放广告。
